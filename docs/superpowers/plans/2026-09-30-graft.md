# Graft Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> Execution mode for this build: native (single session), per the brief ("work autonomously, do not stop").

**Goal:** Ship Graft, a clean-room Electron desktop coding agent matching the reference layout, with a real multi-provider agent runtime, git worktrees/checkpoints, review panels and a Windows installer.

**Architecture:** All privileged work lives in the Electron main process (agent loop, tools, providers, git, pty, db, MCP), exposed to a sandboxed React renderer through one typed preload bridge whose every channel is validated with Zod in main. The agent core (`src/main/agent`, `tools`, `permissions`, `providers`) has no Electron imports so Vitest runs it headless; Electron-specific adapters (safeStorage, dialogs, notifications) are injected.

**Tech Stack:** Electron 44, electron-vite 5 + Vite 7, React 18.3, TypeScript 5.9 (strict), Zustand 5, Radix primitives, lucide-react, Tailwind 4 over CSS-variable tokens, better-sqlite3 13 (N-API, FTS5), node-pty 1.1 (N-API) + xterm 6, @vscode/ripgrep, shiki 4 (JS regex engine, no WASM), `diff` 9, Zod 4, @modelcontextprotocol/sdk, Vitest 5, Playwright 1.63 (`_electron`), electron-builder 26 (NSIS first).

**Spec:** `docs/SPEC.md`

## Global Constraints

- Product name "Graft"; original mark (G-arc + leaf), original pixel mascot "Scion", long-horizon effort mode named "Taproot" (above Max).
- No third-party brand names, glyphs, mascots or copy anywhere in shipped code or assets. Footer copy: "Graft can make mistakes. Review changes before shipping."
- Fonts bundled locally: Newsreader (serif: greeting + chat prose), Geist (UI sans — chosen over Inter because its proportions match the reference widths, see scripts/calibrate-type.mjs), JetBrains Mono (mono). No CDN.
- No model names in renderer code; models come from `src/main/providers/catalog.ts` + live list-models calls.
- Renderer: `contextIsolation: true`, `nodeIntegration: false`, `sandbox: true`, strict CSP, preload exposes only `window.graft` (invoke/on).
- API keys: safeStorage only; plaintext requires explicit opt-in; keys never sent to renderer or logs.
- Every IPC input validated with Zod in main; every tool input validated with Zod.
- Colors, radii, spacing, type sizes only via tokens in `src/renderer/src/styles/tokens.css`.
- Transitions 120–250 ms; `prefers-reduced-motion` and the in-app reduced-motion setting disable motion.
- Minimum window 900×600; must not overflow up to 1920×1080.
- FakeProvider lives under `tests/` only; production bundles must not contain it (checked by grep in Phase 9).

## Review Focus

1. Paths with spaces and non-ASCII (the repo itself lives in `New folder (3)`): every git/shell/rg/pty call uses argv arrays or correct quoting; tests run from this path.
2. A provider stream that dies mid-response (network drop, 529/overloaded after first byte): session shows a retryable error with the partial text kept, never a stuck "running" state.
3. The user interrupts while tools are running in parallel (including a background shell): child processes are killed (whole tree on Windows), results recorded as cancelled, loop exits, queued messages are not lost.
4. Prompt-injected content (file/tool/web/MCP output) instructing the agent to edit `.graft/settings*.json`, hooks, or `.git/hooks`: such writes always require explicit approval regardless of mode; permission rules only change through UI actions.
5. Rewind after the agent created, modified and deleted files (including untracked and gitignored-adjacent files) in a repo with staged user changes: files restored exactly, the user's index and HEAD untouched, preview matches the actual restore.

## Shared interfaces (locked; later tasks consume these names)

```ts
// src/shared/types/effort.ts
export const EFFORT_LEVELS = ['low','medium','high','extra','max','taproot'] as const;
export type EffortLevel = typeof EFFORT_LEVELS[number];

// src/shared/types/models.ts
export type ProviderKind = 'anthropic'|'openai'|'gemini'|'openrouter'|'ollama'|'openai-compatible';
export interface ModelRef { providerId: string; modelId: string }
export interface EffortSupport { levels: EffortLevel[]; recommended: EffortLevel; default: EffortLevel }
export interface ModelInfo { ref: ModelRef; label: string; description: string; family: string;
  contextWindow: number; maxOutputTokens: number; supportsTools: boolean; supportsVision: boolean;
  supportsTranscription: boolean; effort: EffortSupport | null; featured: boolean; cheap: boolean }

// src/main/providers/types.ts
export interface StreamRequest { model: string; system: string; messages: LlmMessage[]; tools: ToolSpec[];
  effort: EffortLevel | null; maxOutputTokens: number; cache: boolean }
export type StreamEvent =
  | { type: 'text-delta'; text: string } | { type: 'thinking-delta'; text: string }
  | { type: 'thinking-signature'; signature: string } | { type: 'redacted-thinking'; data: string }
  | { type: 'tool-call'; id: string; name: string; input: unknown }
  | { type: 'usage'; usage: Usage } | { type: 'finish'; reason: FinishReason };
export interface LLMProvider { readonly kind: ProviderKind; listModels(signal?: AbortSignal): Promise<ModelInfo[]>;
  streamText(req: StreamRequest, signal: AbortSignal): AsyncIterable<StreamEvent> }
export class ProviderError extends Error { code: 'auth'|'rate_limit'|'network'|'bad_base_url'|'not_found'|
  'bad_request'|'context_length'|'overloaded'|'server'|'aborted'|'unknown'; status?: number; retryable: boolean; retryAfterMs?: number }

// src/main/tools/types.ts
export type PermissionClass = 'read'|'write'|'exec'|'network'|'none';
export interface ToolDefinition<I> { name: string; description: string; input: z.ZodType<I>;
  permissionClass: PermissionClass; isConcurrencySafe(input: I): boolean; timeoutMs: number;
  describe(input: I, ctx: ToolContext): ToolCallDescriptor;           // paths/command/url for permissions + UI
  execute(input: I, ctx: ToolContext): Promise<ToolResult> }
export interface ToolResult { ok: boolean; content: LlmToolResultContent; display: ToolDisplay }

// src/main/permissions/engine.ts
export type PermissionMode = 'ask'|'auto-edit'|'plan'|'auto'|'bypass';
export interface PermissionDecision { behavior: 'allow'|'ask'|'deny'; reason: string; dangerous?: string; suggestedRule?: string }

// src/shared/types/agentEvents.ts — AgentEvent union streamed to renderer per session:
// turn-start | assistant-start | text-delta | thinking-delta | tool-call | tool-progress | tool-result |
// assistant-end | permission-request | permission-resolved | question | question-resolved | todos |
// status | usage | compacted | notice | error | turn-end
```

IPC: `src/shared/ipc/contracts.ts` exports `contracts` = record of channel → `{ input: ZodSchema, output: ZodSchema }`; preload exposes `invoke(channel, input)` for exactly those keys; main's router validates input and output. Events: single channel with `GraftEvent` discriminated union (`src/shared/ipc/events.ts`).

## Phase 2 — Main-process core (headless, unit-tested)

### Task 2.1: DB + settings + key store
**Files:** `src/main/db/{database,migrations}.ts`, `src/main/db/repos/*.ts`, `src/main/settings/settings.ts`, `src/main/secrets/keyStore.ts`
- Migrations table `schema_migrations`; tables: settings, providers, secrets, projects, sessions, messages, search_fts (FTS5 trigram), artifacts, schedules, schedule_runs, mcp_servers, permission_rules, onboarding.
- KeyStore takes an injected `Encryptor { isAvailable(); encrypt(s): Buffer; decrypt(b): string }` (safeStorage in prod, test double in tests); refuses plaintext unless `allowPlaintext` setting is true.
- Tests: migrations idempotent, settings defaults/validation, FTS search hits title + body, keystore refuses plaintext, never exposes keys via `list()`.

### Task 2.2: Provider layer
**Files:** `src/main/providers/{types,errors,retry,sse,http,catalog,effort,anthropic,openaiChat,gemini,ollama,registry}.ts`, `tests/support/fakeProvider.ts`
- One `streamText`; adapters translate `LlmMessage[]` (text/image/tool_use/tool_result/thinking blocks) to wire formats; SSE/NDJSON parsers; `withRetry` (429/5xx/overloaded, before first event only, honors retry-after, exponential + jitter); error normalization per HTTP status/body.
- Effort mapping per provider via catalog capabilities; `null` effort = control hidden.
- Tests: SSE parser chunk boundaries; each adapter against recorded wire fixtures via a local `http.createServer` (text, tool calls with streamed args, usage, errors 401/404/429/500, abort); retry/backoff with fake timers; verify() error codes.

### Task 2.3: Tool registry + tools
**Files:** `src/main/tools/*` (read, write, edit, multiEdit, glob, grep, shell, shellManager, bashOutput, killShell, webFetch, webSearch, todoWrite, task, askUser, exitPlanMode, fileState, paths, registry)
- Tests per tool against temp dirs: line ranges/binary/image/size caps; edit unique-match + read-before-edit + stale-file detection; multiEdit atomicity; glob/grep via rg (path with spaces); shell cwd persistence, env persistence, timeout kill, truncation + full log file, background + BashOutput + KillShell; webFetch against local server (html→text, size cap, non-http refused); todo/ask/exitPlan contracts.

### Task 2.4: Permission engine
**Files:** `src/main/permissions/{rules,dangerous,commands,engine,store}.ts`
- Rule grammar `Tool`, `Tool(pattern)`, `Shell(prefix:*)`, `WebFetch(domain:host)`, `mcp__server`, `mcp__server__tool`; scopes user/project/local/session; precedence deny > ask > allow; dangerous commands never auto-allowed; writes outside project root always ask; protected config paths always ask.
- Tests: table-driven rule matching, each mode × class matrix, dangerous detector corpus (rm -rf variants, `git push --force`, `curl … | sh`, credential paths, PowerShell `Remove-Item -Recurse`), path escape via `..`/symlink/case on Windows.

### Task 2.5: Agent loop + compaction
**Files:** `src/main/agent/{loop,session,sessionManager,systemPrompt,compaction,tokens,memory,hooks,slashCommands,skills,subagent,title}.ts`
- Loop: stream → collect tool calls → permission → execute (parallel when all concurrency-safe) → append results → repeat; guards: max iterations (Taproot higher), wall-clock budget, identical-call loop detection; cancellation propagates to tools; provider errors surface as session `error` status with retry; never throws out of `runTurn`.
- Taproot: larger budgets + stop-gate self-review reminder (one extra verification pass before finishing).
- Compaction at ≥ 80 % of context window or `/compact`: summary preserves goal, decisions, todo list, touched files; tail kept verbatim.
- Tests with FakeProvider: plain reply, tool round-trip, parallel read-only tools, permission deny feeds back, interrupt mid-stream and mid-tool, retry on 529 before first byte, loop guard trips, compaction triggers and preserves file list, hooks block a tool, sub-agent isolation.
- Gate: `npm test` green. Commit `feat: main-process core`.

## Phase 3 — Git layer
**Files:** `src/main/git/{git,repo,worktrees,checkpoints,diffStats,changes,pr}.ts`
- Worktrees under `<graftHome>/worktrees/<repo>/<slug>` on `graft/<slug>`; removal refuses dirty trees unless `force` (UI confirms).
- Checkpoints: temp `GIT_INDEX_FILE` → `add -A` → `write-tree` → `commit-tree` → `update-ref refs/graft/checkpoints/<session>/<seq>`; non-git folders use a shadow git dir under app data. Restore via temp index `read-tree` + `checkout-index -a -f` + delete files absent from snapshot; preview = name-status diff.
- Diff stats: numstat vs merge-base (branch ≠ base) or HEAD, plus untracked line counts; cached, debounced.
- Changes: per-file and per-hunk stage/unstage/revert via `git apply --cached/-R` on generated patches; commit; suggest message.
- PR: `gh pr create` when installed + authed; else push + compare URL; normalized errors.
- Tests in real temp repos (paths with spaces): worktree create/cleanup/dirty guard; checkpoint doesn't touch index/HEAD; rewind restores create/modify/delete; stats with untracked; hunk stage/revert.
- Gate: tests green. Commit `feat: git layer`.
